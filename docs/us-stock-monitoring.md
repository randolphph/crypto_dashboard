# 美股价格监控

入口：监控中心 → 添加 → 美股价格。填写股票代码、检查频率和过期阈值，行情来源全自动；创建后在「告警规则」中设置目标价格、触发方向、持续时间、冷却时间，以及 Telegram / Bark 通知目标。未选择通知目标时，仅记录站内告警。

采集与规则执行在 CryptoSentry 后端运行，关闭网页不会停止监控。前端仍通过 `/api/crypto-sentry/*` 服务端代理访问，浏览器不接触后端令牌。无需另建股票数据源 Integration。

## 数据源与时间

- 后台并行查询新浪、Yahoo 和币安，比较有效报价的行情时间，采用最新报价。币安没有对应股票合约时跳过。已有指定来源的监控在升级后统一切换到自动模式。
- 新浪 / Yahoo 提供 USD 股价，默认包含盘前盘后。新浪响应时钟不能代替行情时间。
- 币安先在 USDⓈ-M 合约目录校验 `underlyingType=EQUITY`、可交易状态及永续合约类型，再读取 `premiumIndex` 的 USDT 标记价格。

目标价格的同一数值按实际来源的 USD 或 USDT 比较，不进行汇率换算；币安价格是股票永续标记价格。页面快照及 Telegram / Bark 提醒会标明实际来源与价格口径。所有报价均过期时，不使用旧价格触发到价提醒。

## 持仓共用后台行情

A 股、长桥和 IBKR 的股票持仓及加仓关注列表，会自动向后端登记标的订阅；订阅不创建告警任务。同一市场和代码共用采价，网页关闭或后端重启后继续运行。删除持仓只撤销所属来源的订阅；其他持仓、关注列表或监控仍需要时继续采集。券商同步失败会保留之前的订阅，成功返回空持仓才清除。

持仓默认每 60 秒采价；A 股、港股和韩股在常规交易时间之外降至每 5 分钟刷新。市场状态按交易所时区和常规时段判断，节假日尚未接入交易日日历。前端读取后台缓存的实际行情时间、来源和状态；更新失败保留最近有效价格。后台暂不可用或尚未升级时，页面临时回退原有本地采价，并明确显示「本地备用」。

- A 股：新浪、腾讯。
- 美股：新浪、Yahoo；股票估值仅使用 USD 股票报价，币安 USDT 永续标记价格独立保留供监控使用。
- 港股：腾讯、Yahoo；韩股：Naver、Yahoo，保留原币种。
- IBKR 期权继续使用对应合约的 Flex 报表估值，不拿正股价格替代。持仓、成本和现金仍由原有持仓／券商同步提供，行情更新不会把报表同步变成盘中账户同步。

订阅按本地钱包与随机客户端标识隔离，后端只保存 HMAC 标识及市场、代码，不接收持仓数量、成本或券商凭据。不同浏览器各自登记订阅；换浏览器后旧浏览器登记的订阅仍保留。

后台接口：`POST /stock-quotes/subscriptions` 原子替换单个来源的标的列表，`POST /stock-quotes/query` 查询股票估值报价。采集结果和订阅保存到 SQLite，复用监控调度器，限制并发并共享在途请求。

频率可配置为 5–86400 秒，默认美股使用 60 秒检查、180 秒过期阈值。检查频率不代表数据源更新频率；休市、源数据延迟或网络失败时，不会将旧报价或错误值作为新价格触发警报。

## 后端接口

需要同步部署包含 `stock_price` 类型的 CryptoSentry；目录 `/integrations/catalog` 的 `monitorTypes` 用于前端能力识别。旧后端不会自动获得股票采集能力。

创建监控：`POST /monitors`（经代理对应 `/api/v1/monitors`）

```json
{
  "name": "NVDA 股价",
  "type": "stock_price",
  "enabled": true,
  "intervalSeconds": 60,
  "maxStaleSeconds": 180,
  "config": { "symbol": "NVDA", "provider": "auto", "includeExtended": true }
}
```

规则复用 `POST /rules`，支持 `price` 和 `data_age_seconds` 指标。价格必须大于零；`price` 默认按数据源使用 USD 或 USDT。快照 `/monitors/:id/snapshot` 返回实际来源、币种、价格口径、交易时段和原始行情时间；故障指标为 `error`，陈旧指标为 `stale`，不参与价格触发。

修改或停用任务会中止旧采集任务，丢弃配置修改前的在途结果。启停操作保留原有频率和过期设置。触发、恢复、冷却、通知目标选择和后台投递重试均复用现有规则与通知引擎。

验证使用隔离数据库和模拟通知传输，覆盖定时采集、频率修改、停用、过期/错误报价不触发、冷却及 Bark 投递；不发送真实设备消息。
